# Pixel Bros - Video Editing & Design Agency Website

A modern, responsive portfolio website for Pixel Bros, a video editing and design agency built with HTML, CSS, and JavaScript.

## 🌟 Features

- ✅ **Modern Design**: Clean, professional layout with smooth animations
- ✅ **Fully Responsive**: Optimized for all devices (desktop, tablet, mobile)
- ✅ **Hero Section**: Animated statistics (100+ projects, 15+ clients, 2+ years experience)
- ✅ **Services**: Video Editing, Motion Graphics, and Design
- ✅ **Portfolio**: Showcase sections for design and video editing work
- ✅ **Team**: Mohit Singh & Anis Kashyap profiles
- ✅ **Contact Form**: Integrated with Formspree to receive submissions
- ✅ **Smooth Animations**: Scroll-triggered animations and interactive elements

## 📁 Files

- `index.html` - Main HTML structure
- `styles.css` - All styling and animations
- `script.js` - JavaScript functionality and form handling
- `README.md` - This file

## 🚀 How to Use

1. Open `index.html` in your web browser
2. Or upload all files to your web hosting service
3. The contact form is connected to Formspree and will send submissions to your email

## 🎨 Customization

### Update Content
- **Team Members**: Edit in the Team section of `index.html`
- **Services**: Modify the services section
- **Portfolio**: Add your actual project images in the work section
- **Contact Info**: Update email, phone, and location in contact section

### Update Stats
Change the numbers in the hero section:
- Projects: line 41
- Clients: line 45  
- Experience: line 49

### Update Portfolio Link
The "View All Work" button links to your Google Drive. Update the link on line 162 of `index.html`.

## 📧 Contact Form

The contact form uses Formspree to send submissions to your email. The endpoint is:
