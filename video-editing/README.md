# Video Editing Work Folder

## 📁 Add Your Video Work Here

Add your video projects to this folder. The website will automatically display them in the portfolio.

### Supported File Types:
- MP4 (recommended)
- WebM
- MOV
- GIF (for short looping animations)

### How It Works:
1. Add your video files to this folder
2. Name them with descriptive names like:
   - `commercial-edit-1.mp4`
   - `motion-graphics-demo.mp4`
   - `brand-video.mp4`
3. The website will automatically load and display them

### File Naming Tips:
- Use lowercase letters
- Use hyphens instead of spaces
- Example: `commercial-edit-2024.mp4` (good)
- Example: `Commercial Edit 2024.mp4` (not recommended)

### Recommended Video Settings:
- Format: MP4 (H.264 codec)
- Resolution: 1280x720 or 1920x1080
- Keep file sizes under 50MB for fast loading
- For larger files, host on YouTube/Vimeo and embed

### For Large Videos:
If your videos are large (>50MB), consider:
1. Uploading to YouTube or Vimeo
2. Getting the embed code
3. Adding the embed code to your portfolio
