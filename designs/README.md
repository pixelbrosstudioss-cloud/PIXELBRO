# Design Work Folder

## 📁 Add Your Design Work Here

Add your design images to this folder. The website will automatically display them in the portfolio.

### Supported File Types:
- JPG, JPEG
- PNG
- GIF
- WebP

### How It Works:
1. Add your design images to this folder
2. Name them with descriptive names like:
   - `brand-identity-1.jpg`
   - `packaging-design-1.png`
   - `campaign-poster-1.jpg`
3. The website will automatically load and display them

### File Naming Tips:
- Use lowercase letters
- Use hyphens instead of spaces
- Example: `brand-identity-2024.jpg` (good)
- Example: `Brand Identity 2024.jpg` (not recommended)

### Recommended Image Sizes:
- Minimum: 800px width
- Recommended: 1200px - 1920px width
- Keep file sizes under 2MB for fast loading

---

**Note:** For videos, add them to the `video-editing` folder instead.
